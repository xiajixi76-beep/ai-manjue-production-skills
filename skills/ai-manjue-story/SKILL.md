# AI 漫剧剧本

## 判断故事是否成立

先回答：谁是主角、他想要什么、什么阻碍他、他被迫做什么、行动后什么改变、观众为什么继续看。只有设定、世界观、画风或反转时，先把它们压成行动冲突。

## 输出顺序

1. `一句话故事`：主角 + 欲望 + 阻碍 + 被迫行动 + 代价/看点。
2. `压力系统`：外部压力、关系压力、身份压力、内心压力。
3. `人物卡`：欲望、恐惧、秘密、关键关系、不可逆选择。
4. `单集变化`：一集只完成一个主要变化。
5. `五段结构`：开场钩子 → 处境 → 升级 → 选择/反转 → 结尾钩子。
6. `场景剧本`：每场戏都写目标、阻碍、行动、结果变化。

## 对白规则

对白要带目的：试探、隐藏、争夺关系位置、推动信息、制造误会、暴露秘密或逼迫选择。避免把心理说明直接说出来，优先写潜台词。

## 闸门

若一句话故事不能说清楚，不进入资产制作。若场景删掉后剧情仍然成立，标为可删废戏。若选择没有代价或不可逆后果，标为弱冲突并重写。

## 输出文件

`01-story.md`、`02-script.md`。剧本完成后交给 `ai-manjue-assets` 和 `ai-manjue-storyboard`。
