# 输出模板

选择最小够用的模板。用户明确要求简短、只要提示词或已经给出完整导演判断时，不强行输出全部分析。

## 1. 精简提示词

```text
镜头目的：一句话

生成提示词：一段可直接复制的提示词

验收重点：3 项可观察标准
```

适用于用户只要提示词、快速改写或第二轮微调。提示词中不写“Shot / Light / Space / Story”“史料明确”等分析标签。

## 2. 标准单镜头

```text
镜头目的
一句话写清观众要知道、感到或误判什么。

四维判断
- Shot：观众位置、距离及其理由
- Light：光源、显露与隐藏的信息
- Space：前景 / 中景 / 后景 / 留白的任务
- Story：动作前后、痕迹和未完成信息

决定性瞬间
一个相机能看见的具体状态。

生成提示词
一段可直接复制的完整提示词。

验收重点
- 3～5 项可观察标准
```

## 3. 连续镜头

先写整段目标和连续性锁定项，再逐镜输出：

```text
段落目标：……
连续性锁定：人物、服饰、道具、场景、时间、光线方向、运动方向

shot_id：S01
镜头功能：本镜新增什么信息
决定性瞬间：……
Shot / Light / Space / Story：……
与前镜变化：景别、机位、信息量或情绪距离为何变化
生成提示词：……
验收重点：……
```

每镜必须新增、隐藏或改变信息。避免连续使用相同景别、机位和信息量；若某镜删掉后不影响理解，删除或合并。

## 4. 视频镜头

```text
镜头目的：……
建议时长：3～10 秒

首帧理由
说明首帧为什么能独立成立，以及它为动作留下什么空间。

CATRL 视觉底座
- C：人物连续性锚点
- A：一个主动作
- T：材质与画面纹理
- R：呈现方式与真实度
- L：光源与明暗关系

运镜轴
方向、速度、幅度、起止点、揭示的新信息；无需运镜时明确写固定机位。

演技与时序
- 起始：首帧状态
- 展开：主动作与可见微表情
- 收尾：结束状态
- 硬时序约束：仅在需要时写

完整视频提示词
按连续性锁定 → 首帧 → 主动作 → 运镜 → 次要动态 → 结束状态 → 否定约束组织。

失败降级
先减动作，再减运镜，再换首帧，最后拆镜。

验收重点
- 4～6 项可观察标准
```

CATRL 是分析底座，完整提示词不必机械显示五个字母。一个动作跨不过 3～10 秒时，拆镜而不是加速所有事件。

## 5. 明末历史镜头

在标准单镜头或视频模板后增加：

```text
史料边界
- [史料明确] 视觉锚点 — 实际读取的来源或项目摘要
- [交叉支持] 视觉锚点 — 支持关系
- [合理推演] 创作细节 — 推演链
- [视觉提案] 镜头、光线或节奏 — 戏剧目的
- [待确认] 会实质改变画面的未决项
- 时代错位排除：……
```

没有内容的等级可以省略。证据标签、书名和考据解释不要混入生成提示词；把已核实结论转成可见元素，把待确认项留在提示词之外。

## 6. 参考图分析与重构

```text
原图判断
- 镜头为何存在
- Shot / Light / Space / Story
- 有效之处
- 失效或空泛之处

重构策略
- 保留项
- 改变项及其叙事理由

重构提示词
一段可直接复制的提示词。

验收重点
- 改动后应出现的可观察差异
```

看不到原图时不要假装分析；请用户重新附图，或明确只根据其文字描述提供假设性重构。

## 7. 交接边界

- 用户需要完整项目分镜表时，把本 Skill 的镜头目的和四维判断交给 `ai-manjue-storyboard` 展开。
- 用户已有确定首帧、只需逐秒动态执行时，把 CATRL、运镜轴和演技轴交给 `ai-manjue-video-shot` 深化。
- 交接时保留人物、场景、光线、方向和历史锚点，不重复改写创作意图。
