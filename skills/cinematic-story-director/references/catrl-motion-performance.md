# CATRL、运镜轴与演技轴

本参考用于把已成立的静态镜头扩展成 3～10 秒视频。顺序是：先保住叙事与首帧，再增加动态；不要从“镜头动起来”倒推故事。

## 1. CATRL 视觉底座

CATRL 是视觉起草骨架，不是完整的视频时间线：

- **C — Character**：人物身份、外貌、服饰和必须连续的识别锚点。只保留会影响生成或连续性的特征。
- **A — Action**：一个主要可见动作，包括表情、身体动作和动作方向。不要把多步情节塞进同一镜。
- **T — Texture**：材质、介质和画面纹理，例如潮湿木门、粗布、轻微传感器噪点。避免只写“8K、杰作、电影质感”等空泛品质词。
- **R — Render**：画面属于何种呈现方式与真实度，例如历史叙事写实画面、纪录片观察镜头、手机自拍视频。场景归类通常比堆形容词更有效。
- **L — Lighting**：有来源的光线、方向、色温、明暗关系和连续性。光线必须服务事件信息。

`T` 代表 Texture，不代表 Time。秒级变化、动作先后和禁止出现的时间点，另写在时序层。

## 2. 运镜轴

每镜只选一个主要运镜：

- 固定机位：让表演、遮挡或环境变化承担张力。
- 缓慢推进 / 拉远：改变观众与人物的心理距离或揭示空间关系。
- 横摇 / 俯仰：重新分配信息，跟随视线或揭示上下空间。
- 横向移动：制造遮挡变化、并置关系或空间穿行感。
- 跟随：保持主体关系，同时让环境信息经过画面。
- 小幅环绕：短暂改变人物与背景关系；幅度过大容易破坏一致性。
- 手持：用于不稳定观察或现场感；必须说明轻微程度，不能把随机抖动当电影感。

写清方向、速度、幅度、起止位置和运镜揭示的新信息。若运镜不改变信息或情绪距离，改用固定机位。

## 3. 演技轴

演技轴描述人物内部状态如何变成可见变化：

1. 先写整体情绪目标，而非只写“悲伤、震惊”。
2. 再拆眼神、呼吸、嘴角、下颌、肩颈、手部或重心变化。
3. 允许矛盾情绪同时存在，例如“倔强仍在，但眼神已经松动”；不要把它们排成机械表情切换。
4. 表演幅度服从景别：特写用微表情，远景用姿态和移动方向。

运镜轴负责摄影机的物理变化，演技轴负责人物状态的可见演进。两轴正交设计，再围绕同一镜头目的配合。

## 4. 短视频时序

- 默认时长 3～10 秒，一个镜头只承担一个主动作。
- **起始**：明确首帧人物、物体和摄影机状态。
- **展开**：主动作发生，运镜只在必要时介入；环境最多保留一至两个次要动态。
- **收尾**：动作停在可读状态，为下一镜留下方向或后果。
- 有模型易抢跑的元素时，用硬约束写时间边界，例如“第 6 秒前手部不进入画面”，不要只写“稍后出现”。

## 5. 视频提示词顺序

按以下顺序组合，减少模型误读：

1. 连续性锁定：人物、服饰、场景、时间和不可改变项。
2. CATRL 视觉底座。
3. 首帧状态与摄影机起点。
4. 一个主体主动作。
5. 一个主要运镜及其信息作用。
6. 必要的环境次要动态。
7. 结束状态。
8. 连续性、动作和时序否定约束。

## 6. 失败时的降级顺序

按顺序逐级处理，每次只改变一类变量：

1. 减少动作步骤，只留决定性动作。
2. 降低运镜幅度或改为固定机位。
3. 重做更稳定、姿态更清楚的首帧。
4. 把复杂事件拆成两个镜头。
5. 保留人物与场景锚点后再调整质感或光线。

不要为了让动态“更丰富”同时增加人物动作、镜头运动、天气变化、道具运动和群众运动。

## 7. 验收清单

- 首帧单独截出时，四维叙事判断仍成立。
- 主动作只有一个，3～10 秒内有清楚的起点和终点。
- 运镜改变了信息、关系或心理距离，不是装饰。
- 演技变化符合景别，且可从身体或面部观察。
- 人物身份、服饰、空间方位、光线方向没有漂移。
- 硬时序约束被遵守，次要动态没有抢走主体。
