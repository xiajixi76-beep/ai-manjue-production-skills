# 叙事镜头导演

先决定镜头为什么存在，再决定怎样拍。把“电影感”落实为观众位置、光线动机、空间关系和事件信息，不把 `cinematic`、胶片颗粒、黑边或导演姓名当作答案。

## 读取参考

- 任何任务都先读 `references/shot-light-space-story.md`。
- 涉及视频、动态镜头、首帧、图生视频、运镜或微表情时，再读 `references/catrl-motion-performance.md`。
- 涉及明末、甲申、江阴守城、崇祯、阎应元、《流芳》或《甲申：余烬之末》时，再读 `references/late-ming-evidence-mode.md`，并按其中路径核对现有史料。
- 输出前读 `references/output-templates.md`，按任务模式选择最小够用模板。

## 选择工作模式

1. **单镜头设计**：把一句话变成一张有叙事理由的画面。
2. **连续镜头设计**：把一个事件拆成多个功能不同、前后连续的镜头。
3. **参考图分析**：解释现有画面的镜头、光线、空间和叙事作用。
4. **画面重构**：保留用户指定主体，重做机位、光线、空间或叙事信息。
5. **视频镜头执行**：把已成立的静态镜头扩展成 3～10 秒、一个主动作的可生成视频镜头。
6. **明末历史叙事**：在镜头设计前区分史实、交叉支持、合理推演与纯视觉提案，排除跨朝代和泛古风误植。

用户没有指定时，默认做单镜头设计。缺少非关键细节时给出一个保守假设并继续；只有人物身份、事件方向或画面用途会实质改变方案时才询问。

## 核心流程

### 1. 锁定叙事任务

用一句话写清：`观众要在这一镜知道、感到或误判什么？`

同时提取主体、地点、时刻、情绪、事件阶段和画面用途。不要先选焦段、色调或风格。

### 2. 完成四项判断

依次确定：

1. **Shot**：观众站在哪里，与人物和事件保持什么距离？
2. **Light**：为什么这里此刻被照亮，哪些信息应该留在暗处？
3. **Space**：前景、中景、后景如何组织信息、遮挡和留白？
4. **Story**：这一刻之前发生了什么，之后可能发生什么，画面留下什么未完成信息？

四项必须共同服务同一个叙事任务。若任一选择只是“更漂亮”却不改变观众理解，删除或替换它。

### 3. 选择决定性瞬间

静态画面只表现一个可见状态。把“走进房间”改成“右手推门、门开一半、左脚刚越过门槛”。优先选择动作将发生、刚停止或留下后果的瞬间，少选毫无张力的完成态。

### 4. 转成可执行画面

按以下顺序组织提示词：

`叙事任务 → 主体与决定性瞬间 → 观众位置和镜头 → 光线动机 → 空间层次 → 环境痕迹与未完成信息 → 材质和真实感约束`

先写中文导演方案，再给一段可直接用于图像模型的完整提示词。用户指定模型或语言时适配；未指定时使用自然中文，不强制翻译成英文。

### 5. 视频任务增加动态执行层

先完成四维判断和首帧，再按 `references/catrl-motion-performance.md` 执行：

1. 用 CATRL 固定视觉底座：Character / Action / Texture / Render / Lighting。
2. 分开设计运镜轴和演技轴；两者可以配合，但不能互相代替。
3. 将 3～10 秒拆成起始、展开、收尾，只保留一个主动作。
4. 明确首帧状态、结束状态，以及必要的硬时序否定约束。
5. 生成困难时优先减动作、减运镜或拆镜，不牺牲人物与场景连续性。

注意：CATRL 中的 `T` 是 Texture，不是 Time；时间调度属于独立的时序层。

### 6. 做成立性检查

- 镜头距离是否符合观众应知道的信息量？
- 光源是否有可解释来源，人物明暗是否符合叙事？
- 前中后景是否承担不同作用，而非堆满装饰？
- 画面是否留下事件前后，而不是只摆一个姿势？
- 去掉风格词后，镜头是否仍然成立？
- 视频任务中，关掉运镜后人物动作是否仍清楚，关掉人物动作后运镜是否仍有信息价值？
- 首帧、主动作和结束状态是否能在指定时长内完成？

任一项不成立时先修判断，不靠增加形容词补救。

历史题材还要检查：具体年代、地点、身份、建筑、服饰、器物和行动是否有对应证据等级；未实际读取来源的细节不得写成已确认史实。

## 输出

按 `references/output-templates.md` 输出。默认使用标准单镜头模板；用户只要提示词时使用精简模板；连续镜头、视频和明末历史任务分别使用对应模板。

导演判断、证据标签和解释放在提示词之外。生成提示词只保留模型能看见或执行的主体、动作、镜头、光线、空间、时序与约束。

## 边界

- 不声称复刻具体电影、导演或仍在世艺术家的独特风格；转译为可观察的镜头、光线、空间、色彩和材质特征。
- 不虚构器材事实。焦段不是必要答案；能用空间关系说清时优先说空间关系。
- 不为了“高级”牺牲人物一致性、历史可信度、动作可生成性或用户原意。
- 不替代 `ai-manjue-storyboard` 的完整项目分镜表，也不替代 `ai-manjue-video-shot` 的单镜头动态执行；本 Skill 提供它们上游的导演判断。
