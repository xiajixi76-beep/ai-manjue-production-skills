# 电影摄影规格 → Image 2 提示词

## 目标

将抽象的情绪或故事动作，转成能指导画面生成的摄影决策。输出应像一张可执行的静帧拍摄单，而不是用真实影视作品、导演或摄影师名字做风格捷径。

## 先判断边界

- 这是**静帧** Skill：需要分镜和视频运动时，转给 `cinematic-story-director` 或视频分镜工作流。
- 参考图只提取可迁移的摄影参数；不得复刻受保护角色、可辨认演员、真实作品镜头或水印。
- 不要承诺“精确复原某张图的原始 prompt”。没有原始生成记录时，所有镜头、焦段和调色数值都应标为“复原建议”。

## 输入补全

先从用户提供内容抽取以下信息；缺少时作最小合理假设，并在输出中写明。

| 字段 | 要问或推断什么 |
|---|---|
| 主体与动作 | 谁、正在做什么、动作停在哪一瞬间 |
| 场景与尺度 | 空间、时代/类型、天气、人物与环境比例 |
| 情绪 | 不超过两个相互关联的情绪词 |
| 观看距离 | 亲密、中性观察、疏离或史诗 |
| 交付规格 | 横竖画幅；默认 16:9；写实/动画/插画 |

## 生成流程

### 1. 写一句导演意图

用“让观众感到 X，因此摄影机 Y”的句式，锁定叙事，而不是先写形容词。

例如：`让观众感到少女被日常吞没，因此人物很小，放在空旷田野的右下三分之一。`

### 2. 从六个槽位选择规格

每条最终 prompt 都必须至少落实：构图/镜头、一个光源、一个曝光或色彩决策。

1. **画幅与景别**：2.39:1 宽银幕感、16:9、竖幅；极远景/全景/中景/近景。
2. **机位与构图**：平视、低机位、俯拍、侧后方观察；三分法、前景遮挡、负空间、对称或纵深引导线。
3. **镜头语言**：
   - 18–28mm：环境压迫、尺度、透视；
   - 35–40mm：人和环境同时成立；
   - 50mm：中性、亲近；
   - 75–100mm：压缩空间、孤立人物。
   这些是视觉倾向，不是假称真实相机元数据。
4. **布光**：主光来自哪里、软硬度、是否有轮廓光或画面内实用光；给出明暗关系。
5. **曝光与色彩**：高调/低调、保留高光/压暗阴影、冷暖关系、饱和度、色偏。
6. **空气与材质**：雾、雨、雪、尘、潮湿反光、胶片颗粒、景深；只选真正服务场景的项。

### 3. 合成提示词

按下面顺序写自然语言；中文优先，保留必要的摄影术语。Image 2 通常更擅长具体物理关系而非关键词串。

```text
[画幅/媒介]，[主体与单一动作]，[场景与关键陈设]。
[景别、机位、构图与焦段倾向]。
[主光方向、光质、辅光/实用光与曝光关系]。
[色彩分离、调色、空气和材质]。
画面保持[叙事优先级]，不出现[具体失败项]。
```

### 4. 给出“重试旋钮”

不要一次加十个抽象词。只给 2–3 个可定位改动：

- 人物太抢：改为“极远景，人物占画面高度不超过 12%，保留 60% 天空/环境”。
- 画面太平：明确“单一侧逆光 + 前景遮挡 + 近景虚化”。
- 色彩太脏：指定“阴影偏青灰，高光保持低饱和暖黄，禁止霓虹综合色”。
