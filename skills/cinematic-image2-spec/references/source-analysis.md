## 结论

这批图反复出现的不是某个滤镜词，而是四条稳定关系：

1. 人物尺度和环境尺度先被决定；
2. 光要有来源，且主光往往只有一个；
3. 冷暖对比是局部的视觉锚点，不覆盖全画面；
4. 雾、雨、玻璃、尘土和前景遮挡用于建立深度，而非装饰。

## 可信度边界

- 图像能支持对构图、光向、明暗关系和色彩倾向的视觉判断。
- 图像不能证明原作者具体输入了哪一个英文词、使用了哪个模型参数、哪支真实镜头或后期 LUT。
- 因此，Skill 中的 prompt 是基于可见证据的可用复原，不是对原作者原始资产的逐字还原。
