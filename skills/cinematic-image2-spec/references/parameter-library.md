# 电影摄影参数预设库（Image 2 复原版）

> 这些是从 28 张公开展示图中归纳的可迁移参数，不是原作者公开的 prompt 或真实片场数据。焦段和调色数值均为视觉复原建议。

## P01 冷灰史诗远景

- **适用**：军队、废墟、雪原、城堡、巨物与人物尺度对比。
- **规格**：2.39:1；18–24mm 极远景；低机位或平视；地平线压低，人物/队列形成横向节奏。
- **布光**：厚云形成的大面积冷漫射光；局部不做强补光；轻雾负责拉开远近层次。
- **色彩**：低饱和蓝灰、石墨灰、泥褐；仅保留极小面积火光/旗帜暖色。
- **提示词骨架**：`2.39:1 宽银幕电影静帧，……，18mm 极远景，人物在巨大环境中只占很小比例，阴天漫射冷光，远景被风雪和雾气逐层吞没，低饱和青灰与泥褐，压暗中间调，保留真实雪地/石材/湿泥材质。`

## P02 暖黄田野的青春疏离

- **适用**：成长、离别、孤独、夏末、人物与田野。
- **规格**：16:9 或 4:5；35–50mm 全景；人物位于边缘三分之一，大量绿色或天空留白。
- **布光**：低角度夕阳侧逆光；人物轮廓被暖光轻勾，面部略欠曝但仍可见。
- **色彩**：稻田黄绿、褪色暖黄、灰蓝阴影；中低饱和，不做糖水橙青。
- **提示词骨架**：`电影静帧，……，35mm 全景，人物置于画面右侧三分之一，被广阔田野包围；傍晚低角度侧逆光，发丝和肩部有柔和金色轮廓光，人物面部轻微欠曝；褪色黄绿与灰蓝阴影，细微胶片颗粒。`

## P03 阴雨通勤与日常压抑

- **适用**：车站、教室、走廊、普通出租屋、独处。
- **规格**：35–50mm 中远景；门框、玻璃或前景虚化遮挡；人物偏画面一侧。
- **布光**：阴天窗光或站台天光为主；室内极少量暖实用灯；整体低对比、明亮处不过曝。
- **色彩**：去饱和青绿、湿灰、肤色自然偏暖；可有轻微颗粒。
- **提示词骨架**：`克制的电影静帧，……，从门框后以 50mm 中远景观察，前景轻微虚化遮挡；阴雨天的冷窗光照亮空间，室内只有微弱暖色实用灯，保留潮湿玻璃和旧墙的纹理；去饱和青绿与灰色阴影。`

## P04 暖灯低调室内

- **适用**：卧室、餐桌、秘密谈话、夜晚的疲惫。
- **规格**：40–65mm 中景；人物被家具、门框或窗帘部分包围；负空间保留暗部。
- **布光**：一盏桌灯/台灯作为明确实用主光；窗外或走廊仅有极弱冷补光；深阴影不抬黑。
- **色彩**：钨丝灯琥珀高光、青灰暗部；避免把全屋打亮。
- **提示词骨架**：`低调电影室内静帧，……，50mm 中景，门框形成前景，人物停在暖灯照到的有限区域；一盏钨丝台灯是唯一明确主光，窗外残留很弱的冷蓝环境光，深阴影保留细节但不抬黑，琥珀高光与青灰阴影分离。`

## P05 湿冷战场/灾后空间

- **适用**：战后、地下洞穴、暴雨、怪物/灾难场景。
- **规格**：24–35mm 宽中景；前景有泥、石、树枝或残骸；主体常被放在深景中。
- **布光**：从洞口、云缝或远处火源来的定向侧光；前景明显更暗。
- **色彩**：青黑、冷灰、深褐，局部只有火焰暗橙或微红。
- **提示词骨架**：`阴湿的电影灾后静帧，……，24mm 宽中景，泥泞残骸占据前景，主体处于雾化的中远景；冷硬侧光从……射入，前景近乎黑但保留湿润反光，青黑和深褐为主，仅以远处暗橙火光作视觉锚点。`

## P06 沙漠/异星孤行

- **适用**：荒漠、外星地表、公路、孤身旅人。
- **规格**：18–28mm 大远景；明确地平线与尺度物；人物很小、轨迹引导视线。
- **布光**：低角度日光或被尘土柔化的太阳；天空与地面形成冷暖分层。
- **色彩**：沙褐、褪金、锈红；阴影偏灰紫或青灰，饱和度受控。
- **提示词骨架**：`广阔荒漠的电影静帧，……，21mm 极远景，人物沿着画面中心的轨迹前行，地平线很低；被尘埃柔化的夕阳从侧后方照来，地面是褪金和锈红，阴影偏灰紫，远方在热雾中消失。`

## P07 冷绿城市夜景

- **适用**：小餐馆、公交车、夜间街道、人物警觉或疲惫。
- **规格**：50–85mm 近中景；透过玻璃、座椅或桌面观看；浅景深只服务于主体。
- **布光**：荧光灯/招牌反射形成青绿色顶光或侧光，保留一点暖皮肤或钠灯。
- **色彩**：低饱和蓝绿、黄色外套/灯光为小面积暖对比。
- **提示词骨架**：`都市夜晚电影静帧，……，75mm 近中景，隔着桌面和玻璃观察；青绿色荧光顶光与窗外暗处的暖钠灯微弱交错，阴影保留湿润反射，低饱和冷绿中只保留一处受控暖色。`

## P08 深空孤独与冷暖锚点

- **适用**：飞船、巨型窗景、宇宙、灾难前夕。
- **规格**：18–35mm 宽景；人物作为剪影或小尺度主体，巨型窗/舱门构成几何框架。
- **布光**：窗外冷蓝环境光 + 舱内一处暖色实用光；人物通常半剪影。
- **色彩**：蓝黑、钢灰、低饱和暖琥珀；不要彩色霓虹堆叠。
- **提示词骨架**：`深空电影静帧，……，24mm 宽景，巨大的舷窗/舱门构成几何框架，人物很小并略成剪影；窗外行星提供冷蓝环境光，舱内一盏低亮琥珀实用灯勾出局部轮廓，钢灰与蓝黑主导，画面安静而有尺度。`

## 通用失败约束

按需加入，不要全塞：`避免平面均匀补光、过度磨皮、糖水橙青滤镜、无理由霓虹、全画面同等清晰、漂浮的无来源光、夸张镜头炫光、文字与水印。`
