# cinematic-image2-spec

把故事、角色、场景或参考图转写为适用于 GPT Image 2 / Image 2 的电影静帧提示词。

## 什么时候调用

出现以下需求时直接调用：

- 电影感生图、电影剧照、摄影规格、布光、调色、胶片感
- 用 Image 2 / GPT Image 2 生成真实照片或叙事概念图
- 不想堆“电影感、高清、大片感”，希望明确镜头、光线和色彩
- 需要从参考图提取可迁移的拍摄参数

可直接对 Codex 说：

```text
使用 cinematic-image2-spec，把这个想法写成 Image 2 可直接使用的电影静帧提示词。
```

或：

```text
用 $cinematic-image2-spec 分析这张参考图，给出摄影规格、Image 2 提示词和 3 个重试旋钮。
```

## 怎么使用

输入最好包含：主体与动作、场景与时代、情绪、画幅、写实程度和参考图。缺失信息会采用最小合理假设，并在输出中标明。

Skill 会输出：

1. 导演意图：让观众感到什么，因此摄影机怎么放。
2. 摄影规格（复原建议）：画幅、景别、机位、构图、焦段倾向、主光、曝光、色彩和材质。
3. Image 2 提示词：按自然语言描述物理关系，而不是关键词串。
4. 可选约束：人物尺度、背景、负面限制和一致性要求。
5. 重试旋钮：每次只改变 2～3 个可定位变量。

## 示例

```text
用 cinematic-image2-spec：傍晚，一个女孩站在稻田里，青春期的疏离感，竖图，不要糖水网红感。
```

预期会明确写出人物尺度、竖幅构图、夕阳主光来源、曝光保留方式、低饱和色彩和真实稻田材质。

## 与其他 Skill 的关系

- `cinematic-image2-spec`：下游静帧摄影规格与 Image 2 提示词。
- `cinematic-story-director`：上游叙事镜头动机、连续镜头和图生视频导演判断。

先用导演 Skill 决定镜头为什么存在，再用本 Skill 落成一张可生成的静帧时，可组合调用。

## 边界

本 Skill 的焦段、光比、色彩和参数是基于样图的视觉反向分析与复原建议，不是原作者的原始 prompt 或真实拍摄元数据。不会复刻可辨认演员、受保护角色、具体电影镜头或水印。
